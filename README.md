# Shashoku 写植

為漫畫漢化而做的圖像編輯器。從翻譯到完稿，都在同一個軟體裡。

> [!WARNING]
> 早期開發中，目前還無法使用。

不用把翻譯和嵌字拆成兩個軟體，也不用在 Photoshop 裡一句一句建文字圖層。開一個資料夾就開始：去字、修圖、翻譯、嵌字、校對。擬聲詞也一樣，不是只有對白。完稿之後輸出成圖，或給下游一份分層 PSD。

LLM 翻譯和 AI 修圖都接得進這條路。

一個人從頭做到尾，或是團隊分工，都可以用。

## 有什麼

- **自己的文字引擎**——直排、標點旋轉、Photoshop 的三種描邊位置，以及你自己的字型不必裝進系統就能用
- **真的能編輯的畫布**——選區、圖層、去字，以及拿來手寫擬聲詞的筆刷
- **為漢化而生的東西**——閱讀順序、語意標記、原文與譯文的候選、逐條校對
- **一份工程檔**——狀態只住在一個地方，交得出去
- **Windows、macOS、Linux**

## 致謝

- [LabelPlus](https://github.com/LabelPlus/LabelPlus)——漫畫翻譯標記工具的開創者，本專案翻譯工作流的設計源頭與致敬對象
- [BitMappery](https://github.com/igorski/bitmappery)——瀏覽器像素編輯器的技術棧參考（圖層儲存與復原記錄的先行實作）
- [koharu](https://github.com/mayocream/koharu)——文字引擎技術棧的參考
